# Checklist GDPR

- [x] Exportação e portabilidade no produto.
- [x] Exclusão idempotente de conta e dados primários.
- [x] Fotos privadas por padrão.
- [x] Desenvolvimento isolado de produção.
- [ ] Identificar controlador, DPO/contato e bases legais.
- [ ] Firmar DPAs e listar subprocessadores/regiões.
- [ ] Implementar registro/revogação de consentimento de analytics/marketing.
- [ ] Definir prazos finais e processo de solicitação do titular.
- [ ] Revisão jurídica de políticas e termos.
- [ ] DPIA para fotos/readiness e eventual IA.
